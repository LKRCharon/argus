# 网关验证范围

授权来自设备所有者：将自己的 Mac 和 Windows 接入受信任 Argus 网关，并发布需要 OJ 同款密码的 HTTPS 入口。

本次仅检查 `desktop-bridge` 的网关、两个回环设备桥接、所属专用 SSH 隧道和新建 Nginx 站点。对 OJ 只读使用已有密码校验文件，不修改账号、密码、进度、数据库和服务。没有扫描其他站点，没有导出会话、系统密钥或完整第三方前端。

网络测试限定为本地进程、受信任网关及配置域名，使用隔离测试会话和已知测试密码校验文件。真实用户密码未读取；生产首次人工密码登录仍由用户完成。所有用户会话、截图、真实路径、随机路由及部署凭据仅在私有交付记录中保留。
